# Draft patch notes — food / mill / field-regrow / perf / launch (DO NOT APPLY YET)

1. **No infinite food (T-FOOD-1).** Random skirmish maps now start with ZERO food nodes: seed-wheat strips, straggler fields, wild berries, appended-start food and keep-clear re-plant are all removed. Food comes strictly through the mill cycle — no mapgen free food, no harvest of leftover wild nodes from old saves/debug spawns.
2. **Wild food refused everywhere.** `nearest_res()` skips food nodes without a `mill` tag; `cmd_gather`, `cmd_resow`, `_tick_gather` and `_gather_deliver` drop/refuse wild food with a "Build a mill first" hint, so no detour through gather can farm it.
3. **Mill-cycle only (T-MILL-CORE).** A *finished* mill sows a 7×7 rotated field ring (`_sow_field_ring`, 5 gold per field), peasants resow depleted fields (`cmd_resow`), and auto-regrow runs only for mill-owned fields within 18 m (`FIELD_MILL_RADIUS`).
4. **Field count hard-capped.** `MAX_FIELDS_PER_MILL = 49` stops repeated 60 s re-seeds from ever stacking more fields than the ring can hold (geometric clash check stays as the first line of defence).
5. **Field regrow visuals (T-FIELDS-GFX).** Each food node carries `growth` (0..1) and `regrow_t`/`regrow_time = 60 s` (donor ~60 s seed cycle, driven by `sow_t`); depletion resets growth to 0.
6. **Procedural crop stages.** `_field_growth` + `_draw_field`: full mill fields regrow visibly across the seed cycle, drawn at up to 2.3 tiles wide with the donor `envfieldd` decal and gold tint; `g == 0` renders bare stubble, winter uses a cold tint — no crop-stage sprite exists in the assets, so stages are procedural.
7. **Render perf guards (T-PERF-RENDER).** `sync()` now skips unit/anim redraws while paused with a still camera and gated sim state, and gates the fx layer via `_fx_needs_redraw()` (camera moves, fx items, selection, projectiles, build ghost or armed patrol only).
8. **Cheaper static passes + fog.** Added `fog_revision` so the HUD can skip its full-map dim pass when no fog pixel changed; rally flags/lines are static and only redraw on camera move, dirty sim or `mark_rally_dirty()` after `game.set_rally()`; the 3D sandbox exposes patrol-route activity without a blind fx redraw.
9. **`launch_3d.bat` (human launcher).** From project root, finds Godot (PATH / WinGet / Program Files), runs `res://scenes/terrain3d_sandbox.tscn` with `--stay` by default so the window stays open; forwards args (`--seam-mask`, `--dump res://shots/foo.json`), with a clear install hint if Godot is missing.
10. **`launch_rust.bat` (human launcher).** Finds `cargo`, `cd`s into `rustport/`, builds and runs `cossacks3-rust` in debug (`cargo run -- %*`), with a rustup hint if cargo is missing; args pass straight to the binary.
