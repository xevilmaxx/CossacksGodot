## Mini-baker design / five-fix enforcement

`cavalry.py` imports the read-only reference primitives (`read_oss`, `read_aaf`,
`qmat`, `skin`, `sample`, `camera`, `ground_anchor_ay`, `setup_scene`,
`make_mat`, `dds_to_png`, `tex_png`, `build_mesh`, `render_cell`) and adds only
the cavalry-specific logic. All five UNIT_BAKING_FIX §2 fixes are enforced:

1. **Transposed quaternions** — reference `qmat` used for rider AND mount skin;
   combined geometry verified numerically (C7/C9).
2. **Bone-0 de-travel to one global idle HOME** (per-clip ref only for death) —
   one SHARED rider-root displacement for both meshes (C9); `foot_pin_probe`
   measures the result and reports it (C14).
3. **One stand + one death camera group, centre XZ=(0,0), one projected ground
   anchor each** — `GROUP_OK` check compares `ortho/center/ax/ay` across all
   stand actions, asserts one death group and centre XZ=0; predicted mounted
   dragoon groups in C12.
4. **Projected long-side ortho over 8 azimuths** — same projection math over
   rider+mount union; predicted values in C12, live cross-check in C13.
5. **Attach props baked into the body mesh for the right actions** — for
   cavalry the "prop" is the co-animated MOUNT present in EVERY action; the
   mounted path composites `<base>_horse.oss` as a second material, and
   `mount_composited` asserts it is present in all four actions (and absent in
   rider-only mode). Bonus UV-offset fix in C11.

`--verify` measures every staged sheet cell-locally (alpha>8 union bbox,
`fig_h`, `foot`, `cx`, edge-touch alarm, distinct dirs), compares
frames/duration/loop/tool to AAF truth, and prints a per-unit PASS/FAIL.
`save_crops()` stages 8-direction strips for visual review; Phase 2 will view
them with the read tool as required by the ticket.
