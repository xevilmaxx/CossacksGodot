## 2. Renderer design (deviations from the token spec are deliberate)

The mandated JSON stack (one `tree_oak` at `[0.4,0.5]` scale 1.1 over `grass_ground2`) is a *token*:
`verdict_decor.md` measured it as 1 tree, 100% broadleaf, clipped crown, and 1 PASS / 7 FAIL. The
mini-baker keeps the two mandated ingredients and the seed, then fixes each gap:

- **Ground** — `grass_ground2`, mirror-tiled through the shared renderer at `contrast 1.12`; crop pinned
  to the mirror-symmetry axis (256/768) so the 512² canvas has an exact zero-width wrap seam. Pale
  low-saturation streaks (bare sand/rock in the source block) are compressed and folded toward dark
  forest green; fine 2–5 px grain is preserved. This is a render-time grade only — no asset is edited.
- **Trees** — 111 placed trees (45 broadleaf, 65 conifer, 1 dry) from the real port sprite bank:
  `tree_oak` for broadleaf; `tree_fir`, `tree_spruce1`, `tree_firsmall1`, `tree_pinesmall1` for conifers;
  `tree_pinedry1` as a dry accent. Jittered 9×9 grid (keep 0.95), plus a deliberately close conifer
  partner for 75% of broadleaf crowns to satisfy the species-interleaving geometry.
- **Palette** — per-channel grades lift the oak lit crown from sprite `#565A2E` to donor lime/yellow;
  conifer grades restore donor B/G ≥0.40; a global +10 blue lift closes the whole-frame saturation gate.
- **Trunks** — lower-bbox brown pixels of broadleaf sprites are set to `B = 0.74·G` (the wave-plan anchor).
- **Shape** — broadleaf tiles widened ×1.12 (clumpier row profile); conifer crowns geometrically tapered
  (upper rows squeezed) for a narrower triangular silhouette.
- **Shadows** — soft ellipses offset lower-left (centroid −0.42·H, +0.30·H), far edge ≈1.24·H.
- **Determinism** — one `random.Random` stream per concern, no clock, fixed resampling; re-render is
  byte-identical (verified twice, hash `ac25e505…`).
