## Mini-baker design / five-fix enforcement

`infantry18.py` imports the read-only reference (`bake_sprites.bake_unit`) and
sets its `_ENGINE`/`_SAMPLES` from the CLI. The reference supplies all five
fixes verbatim; the mini-baker adds explicit donor-truth assertions around
them:

1. **Transposed quaternions** — reference `qmat`; local mirror used in the
   foot-pin diagnostic (C4 verifies donor quats are unit).
2. **Bone-0 de-travel to one global idle HOME** (per-clip ref only for death) —
   reference `bake_unit`; `foot_pin_diag()` measures the result numerically (C12).
3. **One stand + one death camera group, centre XZ=(0,0), one projected anchor
   each** — `--verify` GROUP_OK check compares `ortho/center/ax/ay` across all
   stand actions and asserts centre XZ=0.
4. **Projected long-side ortho over 8 azimuths** — reference
   `projected_ortho_group`; live cross-check (C10) + compute_ortho.py audit.
5. **Attach props** — verified absent in the donor (C5); `--verify` asserts
   all `tool: null`, so a future prop appearing would fail loudly rather than
   be silently omitted.

`--verify` also measures each staged sheet cell-locally (alpha>8 union bbox,
`fig_h`, `foot`, `cx`, edge-touch alarm, minimum distinct dirs per row),
compares frames/duration/loop/tool to AAF truth, cross-checks ortho/center/
ax/ay/duration to the live index (read-only), and prints a per-unit PASS/FAIL.
