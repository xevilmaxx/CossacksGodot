live asset. This bake reproduces the latter exactly and the former under the
documented body-only diagnostic, so there is no framing regression. The anchor
is also identical at all 8 azimuths, which is the foot-pin guarantee.

## 8. Acknowledgement — T6-UNITS coordinator directive (T6-S05, 2026-11-23)

Read `docs/research/T6_S05_anim_truth.md` in full (S05 §2.1, §4, §5 R1/R2/R4,
§6, §7). Compliance record:

1. **Walk duration 1.08 s is preserved, never reverted.** `peasants.py`
   defines `WALK_DURATION_PORT = 1.08` and `do_bake()` overwrites only
   `actions.walk.duration` for **every** key it bakes (all 9 walk keys in this
   family), while saving the raw donor value as `actions.walk.donor_duration`.
   `frames` stays at the sampled count 12 (never 20) and duration is NOT
   recomputed from sampled frames — S05 §5 R4. The verifier uses
   `WALK_DURATION_PORT` as the *expected* value, so it cannot mislabel 1.08 as
   a donor mismatch. Provenance: S05 §2.1/R1 → P-26 / agentC2
   (`UNIT_BAKING_FIX.md` §10) + agentSE (§11.2) → GUIDE4 DO-L7.06 stride rule.
2. **Unbaked donor actions stay unbaked — no substitution.** `peaukr.aaf` has
   18 actions; the baker plan covers 14. `idle0` (64..113), `reaction`
   (456..481), `prepare0` (64..65) and `unprepare0` (64..65) are recorded in
   `donor_truth.json -> aaf_action_ranges` but get NO sheet and NO mapping:
   `idle` is selected from the `("idle","idle0")` priority list by first
   present name, and nothing maps `reaction`/`prepare0`/`unprepare0` onto
   `attack`, `idle` or any other existing sheet. This is an intentional scope
   decision (S05 §5 R2). They could only be added as NEW scoped actions with
   their own donor ranges, `sample()` frames and `(end-start+1)/30` duration
   under a separate ticket; none is asserted to be runtime-required.
3. **Runtime state→action binding is UNVERIFIED** (S05 §7.1). Nothing in this
   report claims the unbaked clips are needed by the game, nor that the 1.08
   stride's visual benefit was measured in-engine (S05 §7.2); the latter is an
   inherited documented decision, labelled inferred for its visual effect.

No re-bake or restart was performed for this directive: the peasant bake had
already used the correct 1.08 value, so it was additive documentation only.
