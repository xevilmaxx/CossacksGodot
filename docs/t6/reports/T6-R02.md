## Design facts

- Pixel format is **BGRA**: `Vec<u32>` value `0xAARRGGBB`, memory bytes `[B, G, R, A]`, matching 32-bpp `BI_RGB` DIB byte order on this little-endian host. Documented in the module header.
- Present path: `GetDC` → `StretchDIBits` with `BITMAPINFOHEADER.biHeight = -height` (top-down), `biBitCount = 32`, `biCompression = BI_RGB`, `iUsage = DIB_RGB_COLORS`, `dwRop = SRCCOPY` → `ReleaseDC`. `WM_PAINT` uses `BeginPaint`/`EndPaint` and the same low-level `present_to_dc` helper.
- FFI is raw `extern "system"` against `user32` / `gdi32` / `kernel32`, with locally defined `#[repr(C)]` `RECT`, `POINT`, `MSG`, `WNDCLASSEXW`, `PAINTSTRUCT`, `BITMAPINFOHEADER`, `BITMAPINFO`, `RGBQUAD`. No crates beyond `std`.
- Window state pointer travels through `CreateWindowExW(lpParam)` → `WM_CREATE`/`CREATESTRUCTW.lpCreateParams` → `GWLP_USERDATA`, avoiding mutable globals. The message loop holds no borrow into the state Box across `DispatchMessageW`.
- Input tracked: 256-entry virtual-key table (`WM_KEYDOWN`/`WM_KEYUP`), signed client-space cursor (`WM_MOUSEMOVE`), left/right button flags, client size (`WM_SIZE`/`GetClientRect`). Exposed read-only through `InputState` accessors.
- Anti-hang: `WM_TIMER` kills the timer and calls `PostQuitMessage(0)`; the demo also arms a 4 s watchdog thread that posts `WM_QUIT` to the main thread if the 1.5 s timer never fires. The process exited 0 well inside the watchdog window.
