## 3. Dependencies D1 / D2 / D3

- **D1 — depth-mask resolution** (`world.gd` mask ramp): **IMPLEMENTED**. Sub-tile bake already existed at 4 samples/tile (0.5 m/texel); coverage changed from a hard type-3 tile flag to a continuous `smoothstep(-0.10,0.15, signed_waterline_distance)` from bilinear `game.height_at()`, with a dry-high-ground guard. The wash contour now follows the height field rather than the tile flag. Residual: the height field itself is 1 sample/tile, so a 1-tile (32 px) staircase is still visible; eliminating it needs a higher-resolution height source (outside this grant).

donor's pale-shallow mechanism (projected reflection) is excluded by D3. The
piece-level HARD gate (194,208,201) is therefore **not reproduced in-engine** —
reported, not waived or manufactured. 1-tile height-grid staircase remains (C13).
