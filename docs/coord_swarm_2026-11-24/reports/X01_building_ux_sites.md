# X1 — Building UX exact code sites + donor evidence

**Key finding:** affordability is checked only inside `place_building` (game.gd:3691), never when the ghost is opened or when a build button is enabled; the UI uses *base* cost while placement charges *escalated* cost. Completion is sid-agnostic, so orphan sites (zero selected peasants) are the real "never finishes" path. Rally is applied to spawns but its flag draw has no `selected` test.

Line numbers are as of this scan. Other swarm workers edited `input_controller.gd` (+20) and `world.gd` (−29) *during* recon; symbols/literal strings below are stable, re-grep by symbol before patching.
