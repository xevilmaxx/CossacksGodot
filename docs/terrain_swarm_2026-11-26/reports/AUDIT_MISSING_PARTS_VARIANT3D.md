## 1. Resolution note (the mine-vs-terrain sharpness question)

**[D]** Donor mine albedos are single 2048² textures sampled whole; terrain `terrain_new` cells are 128² atlas subrects further divided into an 8×8 subcell grid = **16 px per authored subcell** vs donor **128 px** (1024/8). Ratio 8× linear / 64× area (AUDIT_ATLAS_RES §2 E1–E4). NEAREST 1024→128 preserves block means ≤0.4/255, so hue is retained but gradient energy drops ~4×; the guard inset then collapses the 16 px cell to a constant at LOD 7 (`terrain_donor_shader.gdshader:367-378`). The measured `240l` flat `(59,56,40)` `R>G>B` matches no used tile mean (all `G>R>>B`) — so darkening is a separate colour/alpha/lighting sampler state **[U]**, not downsampling. Smallest donor-faithful change: bind the on-disk 16384×8192 atlas (or 14-layer partial array, 56/74.7 MiB) with unchanged uniforms; shader `textureSize()` adapts; `packed_lod_offset` returns to 0 (AUDIT_ATLAS_RES §7). Pair with generator histogram fix (88.6% `test8`) — full-res art will sharpen the one tile, not create variety.
