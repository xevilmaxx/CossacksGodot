# RA — Roster gap analysis (Cossacks 3 donor vs Godot port)

Research agent RA, Research lane (`SWARM_OPS.md` §5b). **Read-only on donor and game
code**; this file is the only file written. Donor is private-use only — all donor
facts below come from **public** sources, and no donor asset was copied into the
repo.

Date: 2026-11-21.

---

## 1. Method and evidence standard

- **Donor facts** are taken from public pages only. The strongest source is the
  open **Cossacks 3 Almanac** GitHub repo, whose `data.json` was generated by
  parsing the installed game's `unit.script`, `country.script` and
  `dmscript.global`. I fetched and parsed that JSON directly (5,455,814 bytes;
  `version.extracted_at_utc = 2026-05-17`), plus its public markdown reference.
- **Port facts** are counted by Python from the read-only files named in the
  task; no Godot run, no code edit.
- A gap is **CONFIRMED** only when both sides are countable from the sources
  above. Anything that needs the private donor install to verify (exact `.oss`
  model paths, exact per-nation sprite counts, whether a nation icon is a
  separate mesh or a re-skin) is labelled **UNVERIFIABLE FROM PUBLIC SOURCES**
  and is not used in the headline counts.

## 6. Rigour notes / what is NOT claimed

- **Scotland**: CONFIRMED missing relative to S1/S7 (21 nations). S10 lists 20,
  so a 20-nation "Deluxe" build is a plausible alternate denominator; the port
  matches that 20, but the donor version described by the current public
  game-data extraction has 21.
- **Naval**: CONFIRMED — donor has 7 ship name groups / 8–9 icon families and
  all 21 nations have a Shipyard; the port has zero `UNITS_BASE` ship keys,
  zero `index.json` ship sprites and no `por` building family.
- **Buildings**: the apparent 29-vs-13 gap shrinks after de-duplicating
  localised names; only Cathedral, Shipyard and Palisade/gate/wall variants are
  genuinely new *types*. Do not triage "Hut/Izba/Bazaar/Minaret" as new
  building types — they are nation names for existing families.
- **Units**: 85 named types vs 42 sim types is not a 43-unit gap: many donor
  names are nation tint/mercenary variants the port intentionally folds into
  one type. The confirmed new *named* types are those in G06–G09 (~39 including
  ships and mercenaries).
- **Upgrades**: 889 vs 50 is a real gap but most rows are nation duplicates;
  G13 tickets the generic/unique effects, not all 4483 rows.
- **Formations**: the port already has line/column/square and a hold mode, so
  this is a completeness gap, not an absence of formations.
